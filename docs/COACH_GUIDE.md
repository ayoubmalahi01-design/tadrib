# دليل المدرب
1. **تسجيل الدخول** بالبريد وكلمة المرور. إذا كان حسابك قيد الانتظار فسيظهر لك ذلك حتى توافق الإدارة.
2. **بدء الحصة** من الصفحة الرئيسية، ثم **الحضور**: اختر الحالة لكل تلميذ (حاضر / غائب / متأخر / رخصة / إعفاء). يمكنك البحث بالاسم أو الرقم.
3. **الملاحظات**: افتح ملف التلميذ وأضف ملاحظة. الملاحظة الصحية لا يراها غيرك والإدارة.
4. **إنهاء الحصة** ثم **التقرير اليومي**: الأعداد تُملأ من الحضور، أضف ملاحظاتك ثم أرسل. بعد الإرسال لا يمكن تعديله.
5. **الدفتر الخاص**: لا يراه أحد غيرك، ولا الإدارة.
6. **المحادثات**: ابدأ محادثة فردية أو مجموعة، وأرسل نصاً أو صورة أو ملفاً أو تسجيلاً صوتياً.
7. **دعوة زميل**: من شاشة المحادثات؛ يبقى حسابه معلقاً حتى توافق الإدارة.
