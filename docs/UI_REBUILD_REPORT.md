# تقرير إعادة بناء الواجهة — THE TRAINERS (تدرّب)

**الفرع:** `appjet` · **تاريخ التقرير:** 2026-11-13
**الهدف:** معالجة الشاشة البيضاء/الفارغة، وإضافة الصفحات الناقصة، والتحقق الفعلي من الواجهة.

---

## 1. تشخيص الشاشة البيضاء — بالأدلة

| الفحص | النتيجة |
| --- | --- |
| الموقع المنشور `01.ayoubmalahi01.workers.dev` | **يعرض صفحة الدخول فعلياً** (عربي، حقل بريد، حقل كلمة مرور، زر دخول، استعادة كلمة المرور، مبدّل اللغة) |
| `page_errors` في المتصفح | **لا شيء** |
| `console_errors` | **لا شيء** |
| `network_failures` | **لا شيء** |

**النتيجة:** نقطة الدخول ليست بيضاء. السبب الحقيقي للشاشة الفارغة كان في `src/App.tsx`:

```tsx
if (!profile) return null;   // ← المستند كله يصبح فارغاً
```

أي حساب يُسجّل الدخول بنجاح لكن **لا يوجد له صف في `profiles`** (أو تحجبه سياسة RLS) كان يُرسم كصفحة بيضاء تامة بلا أي رسالة أو مخرج.

**الإصلاح المنفّذ:** استُبدل السطر بشاشة تشخيص حقيقية (`.boot-screen`) تعرض اسم التطبيق، وشرحاً للمشكلة، وزر **إعادة المحاولة** (يستدعي `loadProfile`) وزر **تسجيل الخروج** — فلا يمكن أن يبقى المستخدم في مستند فارغ بعد الآن.

### الصفحات الثلاث الجديدة

**1) `/classes` — الأقسام والمجموعات** (للمشرفين)
- تعمل على جدول `public.classes` الحقيقي: `name` · `academic_year` · `description` · `institution_id`.
- إضافة وتعديل عبر نافذة منبثقة، وحذف بتأكيد صريح (المفتاح الأجنبي يجعل `students.class_id = null`).
- تحسب عدد التلاميذ في كل قسم من `students.class_id`.
- محمية بسياسات `classes_read` / `classes_admin_write` الموجودة في المخطط.

**2) `/sessions` — سجل الحصص**
- يقرأ `coach_shifts` (`started_at` · `ended_at`) مع حساب المدة.
- يحاول جلب عدد سجلات الحضور عبر `attendance_records.session_key`، ويتجاهل خطأ العمود المفقود (`42703`) حتى تعمل الصفحة قبل تنفيذ الترحيل `0001`.
- حالات: تحميل، خطأ مع إعادة محاولة، فارغ، وجدول بيانات.

**3) `/profile` — الملف الشخصي**
- يعدّل **صف المستخدم نفسه فقط**: `full_name` و`preferred_language`.
- يعرض البريد (للقراءة)، المؤسسة، الدور، وحالة الحساب كشارات.
- يتيح تغيير اللغة من داخل الصفحة.

## 4. ما لم يُتحقَّق منه (بصراحة)

1. **الصفحات المحمية لم تُختبر في المتصفح** — تحتاج جلسة مصادقة حقيقية (بريد وكلمة مرور) غير متوفرة في بيئة العمل. تم التحقق منها بقراءة الكود والبناء ونجاح فحص الأنواع، وليس بتشغيل فعلي.
2. **عزل المؤسسات وRLS** لم يُختبر بجلستين حقيقيتين لمؤسستين مختلفتين.
3. **الترحيلان `0001` و`0002`** لم يُنفَّذا على قاعدة البيانات (بانتظار موافقتك).
4. **لم يُنشر أي شيء** إلى Cloudflare ولا إلى أي استضافة، التزاماً بتعليماتك.
