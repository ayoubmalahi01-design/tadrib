## 5. ما لم يُختبر (بصراحة)

| العنصر | السبب |
| --- | --- |
| تسجيل الدخول الحقيقي بكل دور | لا توجد حسابات اختبار في Supabase |
| الصفحات المحمية في المتصفح | يتطلب جلسة مصادقة |
| RLS وعزل مؤسستين | يتطلب جلستين حقيقيتين |
| رفع ملفات وصور ورسائل صوتية | يتطلب Storage وجلسة |
| Realtime بين مستخدمين | يتطلب جلستين |
| PWA والتثبيت والعمل دون اتصال | يتطلب HTTPS ومتصفحاً حقيقياً |
| تنفيذ الترحيلات | موقوف بطلبك |

لم تُعدّ أي من هذه ناجحة، ولم تُخفَ أي نتيجة فاشلة.
