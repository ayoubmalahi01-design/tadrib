## 1. ما أُنجز في هذه الجولة

### 1.1 سير عمل مراجعة التقارير اليومية (مكتمل برمجياً)

كان سابقاً: المدرب يحفظ مسودة أو يرسل، والإدارة تعتمد فقط (`reviewed`). لم تكن هناك
حالة «يحتاج تعديلاً»، ولا ملاحظة مراجعة، ولا إعادة إرسال بعد الإرجاع.

الآن:

| العنصر | الملف |
| --- | --- |
| منطق الحالات والصلاحيات (دوال نقية) | `src/lib/report-workflow.ts` |
| ترحيل إضافي لتوسيع الحالات والأعمدة | `supabase/migrations/0004_report_review_workflow.sql` |
| نافذة مراجعة: اعتماد / طلب تعديل + ملاحظة | `src/App.tsx` (مكوّن `Reports`) |
| شارات حالة مترجمة + عرض ملاحظة المراجعة للمدرب | `src/App.tsx` + `src/lib/i18n.ts` |
| اختبارات (13 اختباراً) | `tests/report-workflow.test.ts` |

الحالات المدعومة: `draft` → `submitted` → `reviewed` أو `needs_changes` → إعادة إرسال
على **نفس السجل** (لا إنشاء تقرير جديد لكل حفظ).

قواعد الصلاحيات المطبّقة في الكود:

- المدرب يعدّل تقريره فقط، وفقط في `draft` أو `needs_changes`.
- المدير/عضو الإدارة يراجعان ولا يعدّلان محتوى المدرب.
- التقرير المعتمد مقفل للجميع.
- مالك المنصة لا يملك صلاحية مراجعة داخل المؤسسة.

### 1.2 أنواع ملاحظات التلاميذ

كانت الملاحظة تُحفظ دائماً بنوع `general` دون إمكانية اختيار. الآن قائمة منسدلة
(عام / سلوك / انضباط / تقدّم / أخرى) مرتبطة بعمود `student_notes.note_type`، وتُعرض
شارة النوع مع التاريخ في سجل الملاحظات.

### 1.3 الترجمة

أُضيفت 11 مفتاحاً جديداً في القواميس الثلاثة (اعتماد التقرير، طلب تعديل، ملاحظة
المراجعة، شارات الحالات، إشعار إضافة ملاحظة). القواميس الآن **314 مفتاحاً في كل لغة**
بتطابق كامل يتحقق منه `tests/i18n-parity.test.ts`.

### 1.4 التوثيق

ثمانية مستندات: هذا التقرير، `FEATURES_STATUS.md`، `ROLES_AND_PERMISSIONS.md`،
`SECURITY_REPORT.md`، `TEST_RESULTS.md`، `CHANGELOG.md`، وتحديث
`DATABASE_REQUIREMENTS.md` و`DEPLOYMENT_READINESS.md`.

## 6. ما لم يُتحقق منه

1. **الصفحات المحمية في المتصفح** — لا تتوفر حسابات دخول حقيقية (مالك، مدير، مدرب).
2. **RLS وعزل المؤسسات** — لم تُختبر بجلستين حقيقيتين؛ الحماية مقروءة من السكربت فقط.
3. **الرفع إلى Storage وRealtime والرسائل الصوتية** — تحتاج جلسة مصادقة وجهازاً.
4. **PWA والتثبيت والعمل دون اتصال** — يحتاج متصفحاً حقيقياً وخدمة HTTPS.
5. **تنفيذ الترحيلات** — موقوف بطلبك.
6. **النشر** — موقوف بطلبك الصريح.

هذه ليست ادعاءات نجاح؛ هي حدود واضحة لما أمكن إثباته.
