# دليل الإدارة
- **مالك المنصة** (`ayoubmalleh772@gmail.com`): ينشئ المؤسسات ويدعو مدير كل مؤسسة.
- **المدير**: يدعو الإداريين والمدربين ويوافق على الحسابات المعلّقة.
- **الإداري**: يدير التلاميذ (إضافة، تعديل، أرشفة، استيراد من Excel بالنسخ واللصق)، والملفات الطبية، والتعاميم، ويراجع التقارير ويطلع على سجل النشاط.
- **مراجعة التقرير**: افتح التقرير المرسل ثم اضغط مراجعة. التقرير النهائي لا يُعدَّل.

- الخصوصية: لا تطلع الإدارة على الدفتر الخاص بالمدربين.
